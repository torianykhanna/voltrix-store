# Voltrix Store

Voltrix Store is a modern e-commerce web application built with **React and TypeScript**.  
The application allows users to browse products, filter and sort items, view detailed product pages, and manage a shopping cart and favorites list.

The project demonstrates scalable React architecture with reusable components, context-based state management, and integration with external services.

## Getting Started

Follow these steps to run the project locally.

### Clone the repository

```bash
git clone https://github.com/toriankyhanna/voltrix-store.git
cd voltrix-store
```

### Install dependencies

```bash
npm install
```

### Run the project locally

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```

---

## Build the project

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Features

Key features implemented in the application:

- Product catalog with pagination
- Sorting and filtering products
- Product details page
- Shopping cart functionality
- Favorites (wishlist)
- Responsive design
- Product image slider
- Authentication with Supabase
- Google OAuth login
- Internationalization (multiple languages)
- Skeleton loaders for better UX
